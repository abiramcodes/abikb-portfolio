# Abiram — Portfolio

Personal portfolio of Abiram, Frontend Engineer at Deloitte USI.
Live at [www.abikb.xyz](https://www.abikb.xyz).

## Stack

- [Astro](https://astro.build) (static output) + Tailwind CSS v4
- Geist Sans / Geist Mono, self-hosted (SIL OFL 1.1, license files in `public/fonts`)
- Deployed to GitHub Pages via `.github/workflows/deploy.yml` (pnpm)

## Develop

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
pnpm preview
```

## Notes

- Open-source hover cards fetch GitHub metadata at build time only
  (snapshots in `src/components/OpenSource.astro` cover dev and failures).
- Icons and the OG image are generated by `scripts/generate-icons.mjs`
  from `public/favicon.svg`; outputs are committed.
